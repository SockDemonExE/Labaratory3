\# Лабораторная работа №3



\## Описание проекта



Консольное приложение на языке \*\*C#\*\*, разработанное в рамках лабораторной работы №3 по дисциплине «Основы программирования».



Программа представляет собой интерактивное меню, предоставляющее пользователю доступ к нескольким функциям: математической загадке, простому математическому тесту, сравнению алгоритмов сортировки массивов и информации об авторе.



\## Функциональность



Программа включает пять основных пунктов меню:



1\. \*\*Отгадай загадку\*\*

&#x20;  - Пользователь вводит два угла в градусах.

&#x20;  - Программа вычисляет результат математической функции.

&#x20;  - Пользователю предоставляется три попытки, чтобы угадать ответ.

&#x20;  - Результат округляется до двух знаков после запятой.



2\. \*\*Простой математический тест\*\*

&#x20;  - Генерируются три случайных математических примера.

&#x20;  - Используются операции сложения, вычитания и умножения.

&#x20;  - Пользователь вводит ответы, после чего программа подсчитывает количество правильных.



3\. \*\*Сортировка массива\*\*

&#x20;  - Создаётся массив случайных целых чисел в диапазоне от -100 до 99.

&#x20;  - Пользователь выбирает два алгоритма сортировки для сравнения.

&#x20;  - Измеряется время выполнения каждого алгоритма.

&#x20;  - При размере массива не более 10 элементов выводится исходный и отсортированный массив.



&#x20;  Реализованы следующие алгоритмы:

&#x20;  - Сортировка пузырьком (Bubble Sort).

&#x20;  - Сортировка выбором (Selection Sort).

&#x20;  - Сортировка вставками (Insertion Sort).

&#x20;  - Сортировка Шелла (Shell Sort).

&#x20;  - Сортировка перемешиванием (Shaker Sort).

&#x20;  - Гномья сортировка (Gnome Sort).



4\. \*\*Об авторе\*\*

&#x20;  - Вывод информации об авторе программы.



5\. \*\*Выход\*\*

&#x20;  - Завершение работы программы с предварительным подтверждением пользователя.

\- \*\*Платформа:\*\* .NET.

\- \*\*Среда разработки:\*\* Visual Studio.

\## Особенности реализации



\- Программа построена на основе методов, разделяющих функциональность на отдельные логические блоки.

\- Для обработки пользовательского ввода используются `int.TryParse()` и `double.TryParse()`.

\- Для генерации случайных чисел применяется класс `Random`.

\- Для измерения времени выполнения алгоритмов используется класс `Stopwatch`.

\- Для копирования массивов применяется метод `Clone()`.

\- Навигация по программе осуществляется через консольное меню.
